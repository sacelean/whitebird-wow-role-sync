# Publicar el contexto tras un despliegue

El paso Record verified deployment se ejecuta después de que scripts/deploy-oci.sh compruebe la conexión a Discord. Activarlo con variable CONTEXT_REPORT_ENABLED=true y secret WHITEBIRD_CONTEXT_WRITE_TOKEN, token fino con Contents: read/write solo sobre sacelean/Whitebird-context. El agente no recibe ese token. El paso registra deployments/<id>.json con SHA completo y run; su commit dispara la pipeline del contexto. Si falla la notificación, revisar ese paso: el bot ya se ha desplegado. No volver a desplegarlo solo para corregir la notificación; reejecutar el registro con los datos del despliegue verificado. Mantener knowledge/bots.json con implementedRevision igual al SHA explicado, fuentes, fecha y textos correctos. Sin coincidencia la ayuda nueva no se activa. Ver Whitebird-context/knowledge/README.md. No se han configurado secretos ni activado esta integración.
